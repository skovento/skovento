## Replacing / adding images
- Admin panel: Industries / Projects / Case Studies / Blog / About have an **Image URL** + **alt text** field. Use `/images/<file>.jpg` (put the file in `public/images/`) or a full https link.
- Best size: 1280×800 landscape JPG, under ~150 KB. Always write a descriptive alt text.
- The About image is a stock photo: keep captions neutral (do not call it "our team").
